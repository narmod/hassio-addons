# PokerTH Server

PokerTH dedicated server (2.1.x), built from the official sources — host your own Texas Hold'em games on your Home Assistant box and join them from the PokerTH desktop/mobile clients or the PokerTH Web Client app (LAN mode).

**Heads-up:** the server is compiled from source when the app is installed. On a Raspberry Pi this can take 30–60 minutes (a one-time cost).

Full documentation: see the **Documentation** tab.
