# PokerTH Web Client

Official PokerTH web client (PWA) served by your Home Assistant box — play Texas Hold'em on the official pokerth.net servers or on any LAN PokerTH server, straight from a browser.

Admin page: `http://<your-ha-host>:8080/admin` (set `admin_token` in Configuration first).

**Local network only:** Nabu Casa / the HA cloud URL does not tunnel the app's port. Away from home, play on https://webclient.pokerth.net instead.

Full documentation: see the **Documentation** tab.
