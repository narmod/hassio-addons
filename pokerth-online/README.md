# PokerTH Online add-on

Puts the **official hosted PokerTH web client** (https://webclient.pokerth.net) in your Home Assistant sidebar. Nothing runs locally — the page simply embeds the official client, so it also works when you access Home Assistant remotely (e.g. through Nabu Casa).

Prefer a self-hosted client on your LAN? Use the **PokerTH Web Client** add-on instead.
